- **混合架构**：采用 Tauri 2 (Rust) 作为后端容器处理系统级交互（窗口置顶、透明化、文件系统访问），React 19 (TypeScript) 作为前端渲染层。
- **前端分层**：`src/hooks` (usePetState, useChat) 封装核心业务逻辑与状态流转；`src/services` (pipeline, llm, memory) 负责数据处理流水线、LLM 调用及持久化；`src/components` 实现 UI 视图。
- **后端接口**：Rust 侧通过 `commands.rs` 暴露 `read_file`、`write_app_json` 等指令，并通过 `window.rs` 监听拖拽事件向前端发射 `file-dropped` 信号。
- **数据流**：文件拖拽触发 Rust 事件 -> 前端接收并启动 `processFiles` 流水线 -> 调用 LLM 进行分块/直接摘要 -> 更新 `core_memory` 并驱动 Live2D 宠物状态变化。
